# 🚒 Kvaltík FIRE ALERT (Android)

Přehled veřejně publikovaných zpráv o hasičských zásazích v Česku. Umožňuje výběr kraje, orientační mapu, uložené stanice a místní oznámení na nové články pouze při otevřené aplikaci.

**Není to oficiální svolávací systém HZS**, nepřipojuje se ke KOPIS, neukazuje všechna nasazení jednotek ani aktuální polohy zásahů. V nouzi 150/112.

## APK
Otevři kartu **Actions → Sestavit APK → Run workflow**, potom stáhni artefakt `Kvaltik-FIRE-ALERT-Android-APK`. Obsahuje testovací `app-debug.apk`.

Build: JDK 17, Gradle 8.11.1, Android SDK 35, Android Gradle Plugin 8.9.2. Projekt lze otevřít v Android Studiu.
